# 发票打印排版处理工具

把多张电子发票（PDF / 图片）合排到一张纸上，生成排好版的 PDF 拿去打印。
全部处理都在本机浏览器里完成，文件不会上传到任何服务器，断网也能用。
当前版本 v1.8.1。

## 功能

- 支持 PDF、JPG、PNG；自动识别手机照片的 EXIF 方向并转正
- 两种排版模式：
  - **标准留白**：按「列数 × 行数」网格排布，页边距、发票间距可调
  - **贴边无白边**：发票紧贴纸边、互相紧贴，每排独立算高度铺满纸宽，只在交界处留裁剪虚线
- 常用排布一键切换（2 / 4 / 6 / 9 张），纸张支持 A4 竖版、A4 横版、A5 竖版
- 自动旋转占满格子（横向发票自动转 90°）
- 实时预览：改任何设置自动重排；可整页 / 适宽 / 100% 查看，点一下预览图可放大核对内容
- 排版设置记忆在浏览器本地，下次打开自动恢复
- 拖拽调整发票顺序、按文件名排序

## 使用方法

### 方式一：离线版（日常使用，推荐）

先用构建脚本生成单文件离线版（约 3.9 MB，已把排版引擎、中文字符映射表、标准字体全部打进一个 HTML 文件）：

```bash
node build-offline.mjs
```

生成 `发票打印排版处理工具-仙儿-离线版.html`，双击用浏览器打开即可。不依赖网络，也不需要和任何文件夹放在一起，可以随便拷贝。

### 方式二：开发版（改代码时用）

`发票打印排版处理工具-仙儿.html` 是开发版，需要和 `lib/` 文件夹放在一起，并通过本地 HTTP 服务打开——不要直接双击 file:// 打开，浏览器会拦截 file:// 下的 worker 脚本：

```bash
# 在项目目录下任选一个：
python3 -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000/发票打印排版处理工具-仙儿.html`。
改完源码后重新跑一次 `node build-offline.mjs`，离线版才会更新。

## 构建说明

`build-offline.mjs` 做三件事：

1. 把 `lib/` 里的 pdf.js 和 pdf-lib 内联进页面，替换掉外链脚本
2. 把 pdf.worker.min.js 以 Blob 方式注入——worker 不能当普通脚本内联，file:// 下也不允许加载本地 worker 路径
3. 把 168 个 CMap 字符映射表和标准字体转成 base64 内嵌——这是中文发票文字能正常显示的关键，缺了就会只剩表格线和印章

构建只依赖 Node.js 内置模块，不需要 `npm install`。

## 已知限制

- 不支持 OFD 格式（铁路电子发票可在 12306「已开票」里重新下载为 PDF）
- 加密的 PDF 可以尝试排版，但内容可能是空白
- 预览最多显示前 12 页，生成的 PDF 不受此限
- 贴边模式无法去掉发票 PDF 页面本身自带的白边
- 打印时请选「实际大小 / 100%」，不要选「适应页面」，尺寸才准

## 隐私

所有处理都在浏览器本地完成：文件读取、渲染、生成 PDF 全部在页面内，没有任何网络请求、上传或统计。
